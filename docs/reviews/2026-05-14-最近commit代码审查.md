## 评审意见

### [建议修改] file:// 前缀处理存在重复代码

**文件:** `internal/source/dir_loader.go`

`Match()` (第 30 行) 和 `Load()` (第 46 行) 中各自独立实现了 `file://` prefix stripping 逻辑：

```go
// Match() 中
path := source
if strings.HasPrefix(lower, "file://") {
    path = source[len("file://"):]
}

// Load() 中
sourcePath := source
if strings.HasPrefix(strings.ToLower(source), "file://") {
    sourcePath = source[len("file://"):]
}
```

**建议：** 提取公共辅助函数，消除重复：

```go
func stripFileScheme(s string) string {
    if strings.HasPrefix(strings.ToLower(s), "file://") {
        return s[len("file://"):]
    }
    return s
}
```

两处都改为调用 `stripFileScheme()`，避免未来逻辑漂移。

---

### [建议修改] DB URL 拦截缺少注释说明

**文件:** `internal/source/dir_loader.go:23-28`

`Match()` 中拦截了 `postgres://`、`postgresql://`、`pg://` 三种前缀，但由于 `DBLoader` 在注册顺序中位于 `DirectoryLoader` 之前，DB URL 不会到达这里。

**建议：** 加一行注释说明这是防御性代码：

```go
// DB URLs are handled by DBLoader (registered before us), but we
// defensively reject them here in case registration order changes.
```

---

### [建议修改] 空目录 warning 应使用 strip 后的路径

**文件:** `internal/source/dir_loader.go:73`

```go
return model.NewSchema(), []error{fmt.Errorf("no .sql files found in directory: %s", source)}, nil
```

`source` 可能包含 `file://` 前缀。建议用 `sourcePath` 替代，使 warning 信息更整洁：

```go
return model.NewSchema(), []error{fmt.Errorf("no .sql files found in directory: %s", sourcePath)}, nil
```

### [仅供参考] fileLoader 懒初始化

**文件:** `internal/source/dir_loader.go:81-84`

当前每次 `Load()` 都检查并创建 `SQLFileLoader`。由于它是无状态的，不会导致 bug。如果未来需要保证单例，可考虑 `sync.Once`。当前实现已经足够。
